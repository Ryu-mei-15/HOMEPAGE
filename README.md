# Miyu Yamaguchi — Research Portfolio

山口瑞悠の研究活動、発表論文、受賞歴、学会参加、対外発表を掲載する個人ポートフォリオサイトです。

エンタテインメントコンピューティング、HCI、音楽情報処理、スポーツインタラクションを軸に、VR野球捕球シミュレータ「CatcherX」などの研究成果を紹介しています。

## サイト構成

このサイトはビルド工程を必要としない静的なHTML/CSS/JavaScriptで構成されています。

| パス | 内容 |
| --- | --- |
| `index.html` | トップページ。プロフィール、ニュース、経歴、論文、受賞、学会、対外発表、ギャラリーを掲載 |
| `news.html` | お知らせ一覧。ピン留め記事を先頭に表示 |
| `NEWS/` | 受賞・採択・大学掲載などのお知らせ詳細ページ |
| `RESEARCH/` | CatcherXなどの研究紹介ページ |
| `fig/` | プロフィール、研究、学会、賞状などの画像 |
| `style.css` | 従来ページの基本スタイル |
| `readability.css` | 全ページ共通の文字サイズ、余白、ボタン、配色補正 |
| `portfolio-redesign.css` | トップページ専用のグリッド・ヒーロー・ギャラリーレイアウト |
| `detail-theme.css` | ニュース・研究詳細ページの最終レイアウト。既存CSSより後に読み込む |

## お知らせの運用

### 新しい記事を追加する

1. `NEWS/` に記事HTMLを作成する。
2. `news.html` の一覧へ、日付・タグ・記事リンクを追加する。
3. トップページにも表示する場合は、`index.html` の `#news-section` に追加する。
4. 日本語・英語の文言を各ページの `translations` に追加する。
5. 各記事上部に以下のリンクを設置する。
   - トップページへ戻る
   - お知らせ一覧に戻る（`../news.html`）

ニュース詳細ページでは、共通CSSを次の順序で読み込みます。

```html
<link rel="stylesheet" href="news-detail.css">
<link rel="stylesheet" href="../readability.css">
<link rel="stylesheet" href="../detail-theme.css?v=20260912">
```

### ピン留め

- ピン留め記事はトップページと `news.html` の両方で先頭に配置する。
- ピン留めは原則1件とし、対象の `<li>` に `pinned-item` を付ける。
- 現在のピン留めは「EC2026で特選セッション発表認定・レコメンデモ認定を受けました」。

### 公開準備中の記事

`NEWS/news_univ_article_ec2026.html` は、EC2026表彰に関する福知山公立大学公式HPの記事掲載後に公開するための下書きです。

大学記事の公開後に以下を行います。

1. 正式な公開日を設定する。
2. 大学公式記事へのリンクを追加する。
3. `index.html` と `news.html` のお知らせ一覧に追加する。

公開前はトップページとお知らせ一覧からリンクしません。

## 多言語表示

各ページ内の `translations.en` と `translations.ja` に翻訳を定義し、`data-i18n` 属性を使って表示を切り替えています。

HTMLを追加・変更した場合は、対応するキーを日本語・英語の両方に追加してください。HTMLタグを含む翻訳では `innerHTML` が使用されるため、外部入力を直接埋め込まないようにします。

## デザイン

基本配色は従来サイトを引き継いでいます。

- ネイビー：`#1e3a8a`
- スカイブルー：`#0ea5e9`
- ゴールド：`#fbbf24`
- コンテンツ背景：白

トップページは12カラムのレスポンシブグリッドを使用しています。ニュース・研究詳細ページでは、白背景と濃紺文字を明示的に指定し、背景との同化を防いでいます。

## ローカルで確認する

リポジトリ直下で簡易HTTPサーバーを起動します。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いて確認します。

確認項目：

- 日本語・英語の切り替え
- トップページとお知らせ一覧のピン留め位置
- ニュース・研究ページからの戻るリンク
- PC・スマートフォンでのレイアウト
- 画像、論文、外部サイトへのリンク

## 公開時の注意

- 公開前の記事が一覧に含まれていないことを確認する。
- 画像やPDFを追加した場合は、ファイル名の大文字・小文字をリンクと一致させる。
- 公開後はキャッシュの影響を避けるため、共通CSSを大きく変更した際にクエリ文字列のバージョンを更新する。
